# Czcionka etykiet (Poppins Bold)

`poppins-bold.json` to kontury glifów podzbioru czcionki Poppins Bold (znaki łacińskie z polskimi, cyfry, interpunkcja),
wygenerowane przez `tools/font2json.py` z pliku `tools/fonts/Poppins-Bold-subset.ttf`.
Copyright 2020 The Poppins Project Authors (https://github.com/itfoundry/Poppins), licencja SIL Open Font License 1.1
(https://openfontlicense.org). Podzbiór jest modyfikacją (okrojenie glifów); nazwa i licencja pozostają bez zmian.
Używa go etykieta „Dla” w Figurkach (`src/figurines/swieta.ts`).
